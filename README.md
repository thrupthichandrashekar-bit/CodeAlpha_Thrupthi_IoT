# CodeAlpha_Thrupthi_IoT
CodeAlpha IoT Internship

This repository contains the tasks and projects completed as part of the CodeAlpha Internet of Things (IoT) Internship. The projects provide practical knowledge of IoT concepts, Arduino programming, sensor-based simulations, and real-world IoT applications.

Topic: Smart Industrial Automation

This task explores the use of IoT in Smart Industrial Automation. The report explains how sensors, connected devices, and IoT technologies help in monitoring industrial processes, collecting real-time data, automating operations, and improving efficiency and safety.

Task 2 – Sensor-Based Simulation

This task demonstrates a basic sensor-based simulation using Tinkercad. An Arduino UNO is used along with a sensor and LED to understand how input signals can be processed and used to control an output device.

The simulation provides practical knowledge of circuit connections, Arduino programming, and basic IoT concepts.
